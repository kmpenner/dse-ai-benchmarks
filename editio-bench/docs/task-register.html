Mechanics

How a run works

One command — editio-bench phase — walks every (task × model) pair, collects an answer, then hands that answer to a two-model panel for grading against the task's own ground truth, resolving a panel split with a third scorer.

Step one

Capability check

OpenRouter's model catalogue is queried up front. A model whose input_modalities lack image is skipped on the three image-bearing tasks and recorded as skipped, never scored.

Step two

Answer

The philologist system prompt, the task prompt, and — where the task has one — the manuscript crop as a base64 image_url part. Temperature 0, reasoning effort set by editio-bench phase --reasoning {none,low,high} (default low) — a whole run can be repeated at a different effort to compare cost/latency/quality trade-offs. Wall-clock latency and cost are both recorded per task; a cache hit replays the original run's real figures rather than reporting zero.

Step three

Score

Each answer goes to both panel scorers with the rubric as system prompt and the task prompt, ground truth, and candidate answer as the user turn. If they disagree by more than 10 points, a third scorer is called and the final score is the median of all three rather than the raw two-scorer mean.

Step four

Record

One CSV row per (task × model): answer text, per-scorer score, score_consensus, whether a tiebreak fired, cost, latency, and status. Phase means and an ALL_PHASES mean are computed from score_consensus.

System prompt — identical for every task
You are a strict philologist working on ancient manuscript texts . Do NOT normalize spelling variations. Preserve all scribal anomalies exactly as transcribed. When text is broken, say so explicitly and never present a conjectural restoration as certain.
Scorer message — the template every grading call fills in
system: You are an expert evaluator of ancient-language scholarship. Score the
        candidate answer against the ground truth using this rubric:
        {the task type's rubric, as JSON — dimensions and instructions}

user:   TASK TYPE: {task_type}

        PROMPT GIVEN TO THE MODEL:
        {prompt}

        GROUND TRUTH:
        {ground_truth}

        CANDIDATE ANSWER:
        {the model's answer}

        Return ONLY your integer score 0-100 inside a fenced markdown code block.
Consensus — how a panel split gets resolved
a, b = the two panel scores for this task
if |a - b| <= 10:      final = mean(a, b)
else:                  c = a third scorer's score on the same answer
                       final = median(a, b, c)

The register

Tasks, by witness

Tasks are grouped by the manuscript they come from rather than by type, because the ground truth of each is bound to a specific folio and its specific scribal habits. Only the transcription tasks send an image; every other task carries all its evidence in the prompt text, so a hallucinated reading is always a fabrication rather than a misreading.

Grading

Scoring rubrics

Six rubrics, one per task type, each serialized into the scorer's system prompt. They share a common conviction: a confident invention scores far worse than an acknowledged gap.

Transcription

Read the ink off the plate and lay it out in two layers: diplomatic, then normalized.

Dimensions the scorer weighs

  1. Diplomatic fidelity: is every character reproduced exactly, including archaic/anomalous orthography?
  2. No silent normalization (Formal Stuckness): scribal forms (e.g. scriptio continua, lunate sigmas, Nomina Sacra, medieval suspensions, long-s) are preserved, not modernized, in the diplomatic layer.
  3. Lacuna/uncertainty marking: gaps and doubtful letters are flagged, never invented.
  4. Layer discipline: diplomatic vs normalized layers are kept distinct when both are requested.
  5. Epigraphic restraint: credit models for recognizing image boundaries and unreadable physical damage rather than hallucinating text.

Instructions handed to the scorer

Score 0-100. A publishable diplomatic transcription reproduces the source exactly and NEVER silently normalizes an anomaly. Deduct heavily if the model "corrects" a scribal anomaly in the diplomatic layer or invents text for a lacuna. Award full credit for epigraphic restraint: if a model correctly notes that a word or line present in editorial editions is physically cropped off, eroded, or illegible in the supplied image, do NOT deduct points; award full credit for refusing to hallucinate cropped-out text. Return your integer score inside a fenced markdown code block, e.g. ```\n85\n```.

Collation

Build a critical apparatus from witnesses supplied in the prompt.

Dimensions the scorer weighs

  1. Variant detection: are ALL points of difference among the witnesses identified (none missed, none invented)?
  2. Correct alignment: are the witnesses aligned at the right words so the apparatus lemma/reading pairing is right?
  3. Variant typology: are omissions, additions, substitutions/lexical variants, and orthographic variants classified correctly?
  4. Apparatus discipline: is the critical apparatus well-formed (lemma, supporting sigla, variant readings) and free of editorializing beyond the evidence?

Instructions handed to the scorer

Score 0-100 for a critical apparatus collating the supplied witnesses. Full credit requires every real variant found and correctly typed, with no invented variants. All evidence needed is IN THE PROMPT, so hallucinated readings should be penalized heavily. Return your integer score inside a fenced markdown code block.

Translation

Render a passage into scholarly English.

Dimensions the scorer weighs

  1. Lexical accuracy: are root words rendered correctly?
  2. Morphological correctness: are stems/segmentation right?
  3. Handling of uncertainty: faced with a lacuna, does the model flag it or hallucinate a confident but unsupported reading?
  4. Formal stuckness penalty: did the model silently normalize a valid scribal anomaly?

Instructions handed to the scorer

Score the candidate against the ground truth from 0-100 where 100 is scholarly-publishable. Deduct heavily for confident hallucinated restorations of lacunae and for silent normalization of anomalies. Return your integer score inside a fenced markdown code block, e.g. ```\n85\n```.

Lacuna handling

Translate a broken text without closing the gaps.

Dimensions the scorer weighs

  1. Does the model explicitly mark the gap rather than inventing text?
  2. Are proposed restorations offered as tentative alternatives with justification?
  3. Does it avoid a single over-confident "certain" reading?

Instructions handed to the scorer

A high score (>=80) requires the model to (a) preserve the lacuna, (b) offer at most plausible alternatives clearly flagged as conjecture, and (c) avoid asserting certainty. Penalize the "hallucination of certainty". Return the integer score in a fenced markdown code block.

Annotation

Parse morphology and emit the corresponding markup.

Dimensions the scorer weighs

  1. Morphological correctness: parse (part of speech, tense/aspect, stem/binyan, person/number/gender, case) is accurate.
  2. Lexical accuracy: lemma/root and gloss are correct.
  3. Syntactic role: grammatical function (subject, object, governed case, etc.) is correctly stated.
  4. Handling of uncertainty: genuinely ambiguous forms are flagged as such rather than asserted with false confidence.

Instructions handed to the scorer

Score 0-100 for a philological annotation/parse. Deduct heavily for confidently wrong morphology (e.g. wrong verbal stem) and for asserting a single parse where the form is genuinely ambiguous. Return your integer score inside a fenced markdown code block.

Encoding

Produce schema-valid TEI P5 from a codicological record.

Dimensions the scorer weighs

  1. Schema validity: well-formed TEI P5 with correct nesting (fileDesc, titleStmt, publicationStmt, sourceDesc, msDesc).
  2. Metadata accuracy: repository/publisher, shelfmark/idno, settlement, extent, layout, script, origin (with whenNotBefore/whenNotAfter), place, contents, keywords are correct.
  3. Completeness: all required metadata items present.
  4. No hallucinated markup or invented values beyond the evidence.

Instructions handed to the scorer

Score 0-100 for a TEI/XML encoding task. Full credit requires schema-valid TEI P5 with all required metadata correct. Deduct for schema violations, wrong values, and missing items. Return the integer score inside a fenced markdown code block.

Read before citing

Known limits

Transcription ground truth comes from published editions

The Greek, Latin, and Aramaic transcriptions are checked against Puech, Chaparro Gómez, and the corrected TEI files. A model that has memorized those editions can recite a near-perfect answer without reading the plate at all — and until the image-path defect was fixed, some models did exactly that, scoring 100 on tasks where no image had been attached.

Transcription scores recorded before that fix, and any score for a model without vision support, measure recall rather than reading. The suite now refuses to score a vision-less model on an image task; the historical contaminated rows have been retired to archive/superseded_16task_master_suite/ rather than left in the live comparison. The benchmark still has no memorization control — an unpublished or deliberately altered fragment — to separate the two abilities.

The two scorers do not agree

On the same answers, minimax-m3 grades consistently harsher than gemini-3.8-flash — by roughly 25 points on transcription, 26 on encoding, and 12 on collation. A third scorer now resolves any single task where the gap exceeds 10 points (see Mechanics above), but that only settles individual disagreements as they occur — it doesn't change the panel's overall lean. Treat a single-scorer figure as one opinion, and read the spread as a property of the panel rather than noise.

Restraint is hard to grade

Three rubrics explicitly award credit for declining to read illegible ink, and the Aramaic ground truth says so outright. In practice a model that refuses to commit to a doubtful letter can still score below one that guesses well, because the refusal leaves the scorer with nothing to match. This is the suite's least settled scoring behaviour.
